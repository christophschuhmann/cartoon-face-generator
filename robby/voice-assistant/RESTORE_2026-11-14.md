# Robby baseline before candidate streaming — 14 November 2026

This snapshot preserves the deployed system **before** the three-candidate,
ASR-guided streaming experiment. It includes the pending Audio Decision Lab,
voice isolation, Parakeet Ultra/Redux and ECAPA workers, parallel output-word
verification, whole-body stunts, unified tool catalogue, actual web retrieval,
verification controls and English architecture diagrams.

The application is here; matching TTS sources are in [tts-runtime](tts-runtime/README.md).
Weights, private configuration, credentials, visitor recordings, memory, voiceprints
and arbitrary logs are excluded. This is a source restore point, not a VM image
or a claim of a tested fresh installation on arbitrary hardware.

## Restore

1. Check out the merge commit containing this document in a separate checkout.
   Preserve uncommitted work when restoring an older version.
2. Follow [setup](README.md), [GPU layout](GPU_LAYOUT_2026-11-09.md),
   [Parakeet](PHOTON_ASR.md), [isolation](INPUT_ISOLATION_UI.md) and
   [parallel verification](PARALLEL_TTS_VERIFICATION.md). Restore credentials
   from your own encrypted store; Git contains none.
3. Keep the production and Photon environments separate. Configure paths for
   your host; the source retains documented workstation paths.
4. Check ownership/health before restarting: Robby8793, TTS8792, Photon8822,
   ECAPA8823 (all loopback). Podcast8816 is a separate project. Reuse the existing
   tunnel and preserve unrelated workers. Model warm-up may take minutes.

## Evidence and limitations

[Tool tests](TOOLS_AND_LATENCY_GUIDE.md), [standard protocol](VOICE_ASSISTANT_TEST_PROTOCOL.md),
[stunts](WHOLE_BODY_STUNTS.md) and [latency](ISOLATION_LATENCY.md) describe reproduction.
131 offline checks, ten real HTTPS typed cases, five model follow-ups and two
synthetic microphone cases passed. Forty authored pose controls and eight
variants were checked; this is not human recognition accuracy. Failed provider
rate-limit/busy-session attempts remain documented.

The subsequent live conversation exposed three final TTS-verification failures
after bounded regeneration and two LLM HTTP429 errors. The strict word gate can
withhold speech and cause retries. Logs cannot distinguish every TTS mistake
from an ASR mismatch. This baseline is not failure-free. The proposed candidate
stream search is **not yet integrated into Robby in this baseline**.

Authored receipts are under static/tools-audit-data; no private conversation
transcript is included. Run scan_staged_release.py before publication.

Export test note: running without the separately bootstrapped TYGER source fails
imports of `app.runtime`. Use `python bootstrap.py` as in setup, or set
`PYTHONPATH=/path/to/pinned/tyger-s2s` when reusing an existing installation.
This external dependency is intentionally not vendored in this source commit.
