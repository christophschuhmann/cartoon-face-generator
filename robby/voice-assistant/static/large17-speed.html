What changed

The pinned merged Large 1.7 release contains 4,129,990,144 parameters. Its FP32 distribution shards are verified by SHA-256 and converted once to private BF16 CPU weights. GPU inference uses BF16 without reapplying the training adapter. Small and Large share the existing MOSS Audio Tokenizer v2.

The unchanged Small package combines cached reference codes, conditional/unconditional branch batching, static semantic KV caches, compiled semantic continuation, CUDA graphs, fast top-k/top-p sampling, the Triton acoustic-token decoder for one candidate, causal codec graphs and fused codec operations. Single-stream chunks grow from 3 to 6 to 12 to 20 frames (240, 480, 960, 1600 ms). Multiple candidates use the original batched local decoder and causal batched codec; the specialized single-row Triton kernels and codec graphs do not silently run as serial candidate inference.

The eager comparison uses the shared runtime’s legacy frame loop with codec fusion and graphs disabled. It is not presented as a benchmark of the release’s standalone CLI. Its streaming chunk is 20 frames; part of the first-audio improvement therefore comes from the smaller initial chunk.

The additional layerwise experiment compiles one transformer block and reuses it for all 36 semantic layers, inside a complete continuation CUDA graph. This reduces the size of the compilation problem. It uses the same BF16 weights, attention mask and KV semantics; teacher-forced state comparisons are included in the raw evidence.

Reference, quality and timing contract

The voice reference is the demo’s fixed synthetic Mira clip, 10.26 seconds. Large 1.7 requires 63–187 reference codec frames; waveform cropping happens before encoding at 14.96 seconds. The reference is cached by content. Shorter-than-supported references are rejected explicitly rather than silently padded or truncated to the historical 2.96 seconds.

Temperature is 0.8, top-p 0.95, top-k 50, repetition penalty 1.0. The main fixture says: “Hallo, schön, dass du da bist. Was möchtest du heute machen?” with a 5-second duration condition. A separate longer story sentence tests continuation. Stop decisions remain model-generated; frame caps are reported. Candidate batches use a fixed base seed per repeat; changing batch size changes RNG consumption and does not guarantee identical samples.

RTF includes semantic prefill, autoregressive generation and PCM decoding, including GPU launch gaps. It excludes reference preparation, prompt packing, ASR, the language model, scoring/ranking, alignment, voice conversion, MP3 and network time. Peak allocated VRAM is this process’s allocator measurement, not total board occupancy. Batch-1 callback timings include synchronization and a CPU copy; larger batches deliver a PCM block for each live row.

ASR transcript checks and teacher-forced state comparisons are smoke checks, not a blinded evaluation of naturalness, emotion or speaker similarity. Listen to the retained clips. Optimized sampling uses a different random stream, so matching seeds are not proof of identical speech.

Browser model switching

Use Voice synthesis near the top of Robby. Small remains the default; Large 1.7 is an explicit choice. Model swaps use a short asynchronous request plus status polling, avoiding Cloudflare’s long-request timeout. New turns wait for the swap. Active replies block model switching. Only one TTS model occupies GPU memory at a time, with verified CPU weights retained for subsequent swaps. The selection controls the shared GPU service.

The first compile is cold work and can take minutes. It is not included in warmed TTFA or RTF. Existing conversation history, face actions, speech recognition, interruptions and LLM selection remain in place. Optional early reaction batching retains the established Small-only path; Large uses ordered sentence streaming.
