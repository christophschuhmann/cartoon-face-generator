Robby: reliable tool routing & visible latency choices

Implementation audit · 14 November 2026 · RTX 3090 · Qwen 27B / Cerebras · Humaneness Small RL.

Real browser integration: True. 10 authored requests, real generated PCM, actual renderer frames and actual returned source links. Regression contracts: 131 passed, 1 warning in 13.09s. Synthetic microphone tier: True.

What changed

Both directors share a capability catalogue. Wake-address variants, serious faces, puppy eyes, cheek puffing and blinking have explicit mappings. Model-selected tools can escalate from the sentence-streaming path, including calls emitted after introductory text. A spoken promise is not used as proof that a tool ran. The same validators enforce bounded visual actions and authorized session rules.

Implicit research requests use the recent subject. News headline requests no longer accidentally filter for the literal words “aktuelle Schlagzeilen”. General web lookup returns actual OpenRouter/Exa source annotations and extracts; it uses the configured API account and incurs search/model charges. No CAPTCHA bypass or unrestricted browser is exposed.

Service and test limitations

The initial model suite exposed missing synonyms, a generic-news-query bug and Cerebras rejecting the search plugin's extra system message. Those were corrected. The burst of API tests also hit HTTP 429 rate limits; those failures are retained rather than relabeled as passes. Provider/API outages remain possible. Existing output-ASR retries can also add latency if a take contains incorrect words. Browser reduced-motion and disabled-action preferences still suppress motion.

An extra final literal-speech browser probe could not acquire the pilot's single conversation slot while a live conversation was active; it is recorded as incomplete, not passed. The running conversation was not interrupted. The equivalent real-model/pipeline test with TTS disabled passed: True. This extra probe is separate from the completed ten-turn HTTPS suite and two microphone cases above. The pilot currently accepts one conversation session at a time.

In a negative German test, native Nemotron misheard “Hey Robby” as “Hey Hobby”, and the wake gate correctly ignored it. Disabling the second recognizer therefore does not preserve German wake-word reliability. A separate English “somer salt” split-word failure was fixed by adding the recognized spelling to the somersault mapping. Microphone, gaze, memory, voice isolation and the podcast service were preserved; this task did not retrain or recalibrate multi-speaker recognition. The existing TTS and podcast processes and Cloudflare tunnel were not restarted. Only the Robby application was restarted to deploy code.
