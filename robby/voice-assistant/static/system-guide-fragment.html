Try German or English. “Noch mal” repeats the last explicit action request. For a sequence, say “Erst wütend, dann eine Grimasse” with a request verb such as “Zeig”. Serious is the authored concentration pose. Emojis such as “Mach so 😡” are also accepted. The renderer uses facial controls, not literal emoji pictures.

Actual tool schemas and how to ask for them
ToolCapability
perform_avatarPerform a gentle visual-only robot action sequence, optionally at a spoken sentence. No hardware movement.
search_webSearch the public web for a short topical query. Use for implicit look-it-up requests and topics outside encyclopedia/news/weather; infer the topic from recent dialogue. Returns real source annotations. Billed through OpenRouter.
search_newsFind latest headlines, optionally filter recent feeds by topic. For latest/current headlines without a specific TOPIC use an empty query, never generic headline words.
get_weatherGet a current weather model estimate and 3-day forecast for a named city. Ask the user if no city is known.
search_wikipediaSearch Wikipedia for a concise encyclopedia extract, with source links.
set_interruption_ruleRegister an explicitly requested live condition for interrupting the current user BEFORE their turn ends.
set_semantic_interruption_ruleRegister an explicitly requested meaning-dependent condition, ONLY when literal named topic/word triggers are insufficient. Requires the decision API during live speech.
clear_interruption_rulesCancel the current user’s explicitly cancelled interruption game/rules.

“Wer war Viktor Frankl?” followed by “Kannst du das mal nachgucken?” retains the topic. The model builds a short query. Web lookup uses the configured OpenRouter account and its paid Exa search plugin; no additional key is exposed to the browser. Search failures stay visible, with no invented sources. Only returned source annotations/extracts are used, not an uncited search model answer.

“Unterbrich mich, wenn ich Bananen sage” installs an explicit session rule. “Stopp”, “Hör auf” and “Warte bitte” use the live interruption path. The internal use_tools helper only selects the validated tool director; it performs no action by itself. Settings, speaker enrollment, persistent memory and news-source links are separate systems; there is no unrestricted shell, motor or general browser-control tool.
