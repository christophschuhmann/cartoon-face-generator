Causal Best-of-3 streaming

14 November 2026 · RTX 3090 · Small 1.1 Alpha RL · CFG 2 · temperature 0.8 · fixed Mira reference.

Enable Speed & verification → Best-of-3 streaming in Robby. The existing single-stream mode remains the default. Three continuations are generated in one batch. Every 12 semantic frames (960 ms of audio), actual ASR word accuracy and progress select a winner. Its complete semantic and codec state are copied into the next three lanes. Already emitted audio is never revised. Optional edge fades reuse these timestamps; there is no extra output ASR pass.

Measured warm comparison

Three seeds per condition. Entries are medians; success counts include failures. First PCM is local HTTP request to received samples, not audible browser onset. RTF is total wall time divided by emitted audio duration, including selection. ASR runs on GPU 1; this is not a one-GPU-only throughput claim. The single stream uses the previous parallel word checker and 1.6-s maximum chunks with its initial ramp. Search uses fixed 960-ms selection chunks.

Zero-reserve gaps assume playback immediately on the first received sample; the browser normally buffers additional audio.

Cold start and limitations

A newly encountered batch shape compiles and autotunes before producing audio. This can take minutes and must not be presented as normal warm latency. The service also warms its existing single/continuous-stream paths at startup.

Search can select incorrect or faster-but-less-natural speech. It does not optimize speaker similarity or enjoyment. ASR uses approximately 12-second rolling windows; later decoding can revise earlier recognized words. Missing openings are bounded to 3.84 seconds of generated audio. Natural endings are checked using selection timestamps, without a second full-text gate. Large, quick reactions and optional idle speech retain their existing paths.

Recovery and browser checks

Transient candidate ASR errors get one retry. Before any published sentence audio, missing openings/empty audio get up to three attempts; a first search OOM falls back to a single stream. Audio that has already played is not replayed. Cancellation remains cooperative at frame/ASR boundaries.
