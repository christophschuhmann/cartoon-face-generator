Whole-body turns, somersaults and spoken reactions

13 November 2026. The normal “Dreh dich im Kreis” request now turns the platform and body together. “Dreh deinen Kopf” retains head-only movement. “Mach einen Salto” performs a crouch, one forward flip and a soft landing. “Mach einen Salto rückwärts” / “Do a backflip” reverses its direction.

Actions use the existing validated perform_avatar vocabulary. Direct requests have a deterministic parser and a unique action ID, so they are scheduled even if the LLM only describes a movement. The browser waits for actual speech playback, or four seconds at most, before starting. Silent requests and UI previews start immediately. Stop, disabled actions and reduced-motion controls remain effective.

Recorded integration checks

Overall result: PASS. Real model calls and public HTTPS; microphone fixtures were generated from authored text. No physical camera/microphone or real-room robustness claim. Request-level passes require actual audio and visible motion during playback.

What was wrong

The original turn only moved the head. The somersault action was missing. A live request also produced a third-person Markdown stage direction instead of words to speak, which failed TTS verification. Later tests found laughter-only replies and an untyped planning failure; those negative receipts are retained. Stage directions and generic laughter-only reactions now trigger bounded regeneration. After two unusable completions, a short local acknowledgment is allowed for a directly requested trick and explicitly marked in metrics. Normal responses remain LLM-generated; optional petting/idle dialogue does not use this fallback. Transient HTTP failures preserve their status for the retry policy. The TTS word gate is not weakened.

Rendering and limits

The existing CPU 3-D renderer transforms all meshes, face texture and surface normals together, after ordinary head articulation. Tests assert movement of actual platform geometry, not only an animation label. A temporary camera pullback keeps the jump visible. During whole-body motion, internal raster size is capped at 360 pixels on its longest edge; normal resolution returns at rest. The older SVG page has a flat cartoon fallback. All tricks are screen effects, never robot motor commands.

The test is a small deterministic command suite, not a guarantee that all paraphrases, speech recordings or API failures work. A four-second animation fallback can precede speech during a longer provider outage. The new code does not address the separately documented background-speaker false match.
